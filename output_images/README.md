# Output Images Directory

This directory stores generated publication figures and application screenshots produced by DevPilot benchmark exporters and documentation capture tools.

## Contents
- `resolve_rate_comparison.svg`: Vector bar chart comparing resolve rates across configurations.
- `precision_recall_tradeoff.svg`: Context retrieval Precision@K versus Recall@K Pareto curve.
- `app_session_overview.png`: Real screenshot of the DevPilot live session dashboard.

All visual assets must be generated from real application runs or real evaluation metrics. Fabricated or synthetic graphic representations are prohibited.
