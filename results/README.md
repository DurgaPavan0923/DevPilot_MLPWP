# Evaluation Results Directory

This directory stores machine-readable evaluation output files produced by DevPilot benchmark runs.

## Contents
- `latest_evaluation_report.json`: Structured trial records, pass rates, token metrics, and statistical test outputs.
- `results_summary.csv`: Tabular trial records for spreadsheet and statistical software import.
- `ieee_results_table.tex`: Ready-to-paste LaTeX tables for publication manuscripts.

Raw run caches and ephemeral trial artifacts are excluded from version control. Only reproducible summary reports belong here.
